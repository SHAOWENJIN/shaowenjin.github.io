Investigating the Influence of Grasp Configuration on the Stability of a Multi-Limbed Robotic Platform in MuJoCo

A comparative study of grasp stability using a modified Unitree GO2 EDU PLUS in a microgravity-inspired structural environment.

MuJoCoPythonRobotics

CategoryMaster’s Project

RoleIndependent MSc dissertation project

Project index02 / 10

Overview

Developed a reproducible simulation and analysis framework to investigate how grasp configuration changes the stability of a multi-limbed robot during assisted transfer on a fixed structure.

Work & contribution

  • Built a modified Unitree GO2 EDU PLUS model and a structured transfer workflow in MuJoCo.
  • Compared four grasp/controller configurations under a common completion gate.
  • Designed a six-metric evaluation covering contact forces, friction utilisation, slip, contact continuity, centre-of-mass displacement and grasp-matrix conditioning.
  • Processed simulation outputs using Python, NumPy and Matplotlib to compare failure modes and operating boundaries.

Outcome

The analysis identified the 4F3P configuration as the preferred reference configuration within the simulated test conditions. Results describe one completed deterministic cycle per system, not independent repeated trials.
